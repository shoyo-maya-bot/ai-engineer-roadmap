## 成果物

CPU で学習できる小さな文字単位の言語モデル（[05-4](05-4-small-transformer.md)）

- モデル: トランスフォーマーのブロック 1 つ（自己アテンション・全結合・残差接続）を NumPy で手書きしたもの。逆伝播も手で書き、数値微分と照合しています
  （`examples/src/roadmap_examples/p05_charlm.py`）
- 実行: `uv run python -m roadmap_examples.p05_charlm --steps 2000 --save charlm.npz`（手元の CPU で 10 秒ほど）
- PyTorch で、層の正規化・複数のヘッド・ブロックの積み重ねを足した版は、05-4 の本文の例です
