## 1 重みの大きさと、前の情報の届き方

```python
from roadmap_examples.p05_attention import first_token_influence


def test_larger_weights_keep_information_longer() -> None:
    for length in (5, 10, 20):
        assert first_token_influence(length, scale=1.5) > first_token_influence(length, scale=0.5)
    assert first_token_influence(20, scale=1.5) < first_token_influence(2, scale=1.5) / 1000
```

手元の結果:

| 文章の長さ | 2 | 5 | 10 | 20 |
|---|---:|---:|---:|---:|
| 重みの大きさ 0.5 | 0.41 | 0.022 | 0.00014 | 0.00000001 |
| 重みの大きさ 1.5 | 0.80 | 0.054 | 0.029 | 0.000024 |

考察の例:

- 重みを大きくすると、影響は長く残ります。それでも、長さ 20 では長さ 2 の 3 万分の 1 ほどに小さくなりました
- 重みをさらに大きくすると、`tanh` の出力が -1 か 1 に張り付き（微分がほぼ 0）、かえって伝わらなくなります。
  逆に、活性化関数の無い RNN で重みを大きくすると、値が爆発的に大きくなります（勾配爆発）
- 「ちょうど良い大きさ」を保ち続けるのが難しいことが、RNN の学習の難しさです

## 2 √d で割る理由

```python
import numpy as np

from roadmap_examples.p05_mlp import softmax


def mean_max_weight(d: int, scaled: bool, seed: int = 0) -> float:
    rng = np.random.default_rng(seed)
    q, k = rng.normal(size=(8, d)), rng.normal(size=(8, d))
    scores = q @ k.T / (np.sqrt(d) if scaled else 1.0)
    return float(softmax(scores).max(axis=1).mean())


def test_unscaled_scores_become_one_hot() -> None:
    assert mean_max_weight(1024, scaled=False) > 0.95
    assert mean_max_weight(1024, scaled=True) < 0.6
```

手元の結果（乱数の種 0。各次元で新しく乱数を作っています）:

| 次元 d | 4 | 64 | 256 | 1024 |
|---|---:|---:|---:|---:|
| √d で割る | 0.26 | 0.28 | 0.38 | 0.40 |
| 割らない | 0.38 | 0.81 | 0.86 | 1.00 |

考察の例:

- 割らないと、次元が大きいほど重みが 1 か所に集まり、d = 1024 ではほぼ 1 位置だけを見ています。8 位置を均等に見れば 0.125 です
- 平均 0・分散 1 の乱数どうしの内積は、分散が d になります（d 個の積の和なので）。`√d` で割ると分散が 1 に戻り、次元に関係なく同じくらいの広がりになります
- 重みがほぼ 0 か 1 になると、softmax の勾配がほぼ 0 になり、学習が進みません

## 3 どの位置を見ているかを確かめる

```python
import numpy as np

from roadmap_examples.p05_attention import attention, causal_mask


def test_position_3_looks_at_position_1() -> None:
    rng = np.random.default_rng(0)
    k = rng.normal(size=(5, 8))
    q = rng.normal(size=(5, 8)) * 0.1  # ほかの位置の Q は小さく（どこも同じくらい見る）
    q[3] = k[1] * 3  # 位置 3 の Q を、位置 1 の K と同じ向きにする
    _, weights = attention(q, k, np.eye(5), causal_mask(5))
    assert weights[3].argmax() == 1
    assert weights[3, 1] > 0.9
    assert weights[3, 4] == 0.0  # 未来（位置 4）は見ない
```

なぜこうするか:

- V を単位行列（`np.eye(5)`）にすると、出力の各行がそのまま重みになり、どこを見たかを出力からも読めます
- Q を K と同じ向きにすると内積が大きくなり、softmax の重みがその位置に集まります。学習では、この「向きをそろえる」重みを、モデルが自分で見つけます
- 因果マスクの確かめも同じテストに入れておくと、見てよい範囲の中で見ていることが分かります
