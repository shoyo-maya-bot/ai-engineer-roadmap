# 10 AI エージェント

!!! abstract "到達目標"
    - ツールを使うエージェントを作り、「どこで人が承認するか」「何回まで動くか」を設計できる

## 前提

- 前提の部: [08 RAG とベクトルデータベース](../08-rag/index.md)（07-3 のツール使用と、07-5 の評価セットも使います）
- LLM はローカルのモデル（Ollama）で動かします。ツール使用に対応したモデルが要ります。演習のコードは `examples/` にあり、テストは LLM を呼びません。
- 起票先は手元のファイル（架空）です。外部のサービスには繋ぎません。クラウドの API を使う演習は任意です。

## 成果物

08 の Q&A に「課題を起票する」ツールを足し、起票の前に人が承認するエージェント（[10-1](10-1-loop-vs-workflow.md)・[10-4](10-4-approval-limits.md)）

- 実行: `uv run python -m roadmap_examples.p10_agent --model <モデル名> --issues issues.jsonl --question "<質問>"`（起票先は手元の JSONL ファイル）
- 評価: `uv run python -m roadmap_examples.p10_eval --model <モデル名>`（`examples/data/p10/agent_cases.jsonl` の 8 件で、動き方を確かめる）
- MCP のサーバー: `uv run python -m roadmap_examples.p10_mcp --issues issues.jsonl`（同じツールを stdio で公開する。[10-3](10-3-mcp.md)）

11 で、このエージェントに攻撃を試します。
