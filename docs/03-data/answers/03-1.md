## 1 profile 関数

```python
import pandas as pd


def profile(df: pd.DataFrame) -> pd.DataFrame:
    rows = []
    for col in df.columns:
        s = df[col]
        counts = s.value_counts()  # 欠損は数えない
        rows.append(
            {
                "column": col,
                "missing": int(s.isna().sum()),
                "unique": int(s.nunique()),
                "top": counts.index[0] if len(counts) else None,
                "top_count": int(counts.iloc[0]) if len(counts) else 0,
            }
        )
    return pd.DataFrame(rows)


def test_profile() -> None:
    df = pd.DataFrame({"a": ["x", "x", "y", None], "b": [None, None, None, None]})
    got = profile(df).set_index("column")
    assert got.loc["a"].tolist() == [1, 2, "x", 2]
    assert got.loc["b", "missing"] == 4 and pd.isna(got.loc["b", "top"])  # 表に入れると None は欠損になる
```

列の数だけの for 文は使ってよい場面です。遅くなるのは「行の数だけの for 文」で、列は 7 つしかありません。
すべてが欠損の列でも止まらないように、`value_counts` が空の場合を分けています。

## 2 生の CSV に使った結果と、直すべき問題

| 列 | 欠損 | 種類 | 最も多い値 | その件数 |
|---|---|---|---|---|
| 受付番号 | 0 | 141 | Q0006 | 2 |
| 受付日時 | 0 | 141 | 2026/4/4 15:48 | 2 |
| 顧客ID | 0 | 60 | K-0014 | 9 |
| 窓口 | 10 | 13 | メール | 26 |
| 本文 | 2 | 139 | 担当の方にお礼を伝えてください。 | 2 |
| 分類 | 6 | 19 | bug | 14 |
| 対応時間（分） | 6 | 75 | 17 | 6 |

見つかる問題の例:

- **受付番号が重複している**: 147 件なのに種類は 141。同じ番号が 2 回出てくる件がある（二重の出力か、後からの修正）
- **顧客 ID の種類が多すぎる**: 顧客は 40 人なのに 60 種類。`K-0003`・`K0003`・`k-0003` のような書き方の違いがある
- **分類が 19 種類の書き方に分かれている**: 正しくは 5 種類。大文字小文字・前後の空白・日本語の別名がある
- **窓口も 13 種類**: 「メール」「mail」「E-mail」「ﾒｰﾙ」など
- **受付日時の書き方がまちまち**: `2026-04-01 14:36` と `2026/4/4 15:48` と `2026年4月8日 17:37` が混ざる
- **対応時間に「分」が付いた値や、数でない値がある**: 数として計算できない

## 3 strip と lower でそろえた窓口

```python
c = df["窓口"].str.strip().str.lower()
print(c.nunique())  # 11
print(sorted(c.dropna().unique()))
# ['chat', 'e-mail', 'mail', 'tel', 'web フォーム', 'チャット', 'フォーム', 'メール', '問い合わせフォーム', '電話', 'ﾒｰﾙ']
```

13 種類が 11 種類に減りました（`Chat` と `chat`、`TEL` と `tel` がまとまった）。
まだ残る表記ゆれは、半角カナの「ﾒｰﾙ」と全角の「メール」、英語と日本語の別名（mail とメール、tel と電話）です。
半角カナは Unicode の正規化（NFKC）でそろえられますが、別名は対応表が要ります。どちらも 03-3 で扱います。
