# 07 プロンプトと API

!!! abstract "到達目標"
    - LLM の出力を JSON で受け、検証・再試行・費用上限つきで業務コードに組み込める

## 前提

- 前提の部: [06 LLM の基礎](../06-llm-basics/index.md)
- 比べる基準として 04 の成果物を使います。04 の結果がまだ無いので、いまは仮のルールベース分類を基準にしています（[07-5](07-5-eval-set.md)。04 ができたら差し替えます）。近道で 04 を飛ばした場合も、この基準と比べます。
- LLM はローカルのモデル（Ollama）で動かします。演習のコードは `examples/` にあり、テストは LLM を呼びません。
- クラウドの API を使う演習は任意です。ローカルのモデルだけで成果物を作れます。

## 成果物

04 の分類を LLM でやり直し、同じ評価セットで精度と費用を比べる（[07-5](07-5-eval-set.md) の表）

- 評価セット: `examples/data/p07/inquiries.jsonl`（架空の問い合わせ 30 件）
- 実行: `uv run python -m roadmap_examples.p07_classify --mode baseline` と `--mode ollama --model <モデル名>`

評価セットと LLM を呼ぶ部品は、08・09・11 で使います。
