# 07-3 解答

[07-3 関数呼び出しとツール使用](../07-3-tool-use.md) の演習の解答の一例です。

## 1 ツールを足す

```python
from roadmap_examples.p07_tools import SUPPORT_TOOLS, Tool

PLANS: dict[str, dict[str, str]] = {
    "M-001": {"plan": "スタンダード", "renews_on": "2026-05-01"},
    "M-002": {"plan": "ライト", "renews_on": "2026-04-15"},
}


def get_plan(member_id: str) -> dict[str, str]:
    if member_id not in PLANS:
        raise KeyError(f"会員番号 {member_id} は見つかりません")
    return {"member_id": member_id, **PLANS[member_id]}


PLAN_TOOL = Tool(
    "get_plan",
    "会員番号から、契約中のプラン名と次の更新日を調べる",
    {
        "type": "object",
        "properties": {"member_id": {"type": "string", "description": "会員番号（例: M-001）"}},
        "required": ["member_id"],
        "additionalProperties": False,
    },
    get_plan,
)
TOOLS = [*SUPPORT_TOOLS, PLAN_TOOL]
```

なぜこうするか:

- 見つからないときは `KeyError` にします。`call_tool` が `KeyError` を受け止め、`{"error": ...}` としてモデルに返します
- 説明（description）に「何から何を調べるか」を書きます。モデルはこの文章でツールを選びます
- 引数の説明に例（`M-001`）を書くと、モデルが形を合わせやすくなります

## 2 呼び直しの流れのテスト

```python
import json

from roadmap_examples.ollama_client import ChatTurn, ToolCall
from roadmap_examples.p07_tools import FakeToolChat, run_with_tools


def test_model_retries_after_unknown_member() -> None:
    chat = FakeToolChat(
        [
            ChatTurn("", [ToolCall("get_plan", {"member_id": "M-999"})], 80, 10),
            ChatTurn("", [ToolCall("get_plan", {"member_id": "M-001"})], 120, 10),
            ChatTurn("次の更新日は 2026-05-01 です。", [], 160, 15),
        ]
    )
    run = run_with_tools(chat, [{"role": "user", "content": "M-001 の更新日は？"}], TOOLS)
    assert run.steps == 3
    first_result = chat.calls[1][-1]
    assert first_result["role"] == "tool"
    assert "見つかりません" in json.loads(first_result["content"])["error"]
    assert run.text.endswith("2026-05-01 です。")
```

なぜこうするか:

- 2 回目の呼び出し（`chat.calls[1]`）の最後のメッセージが、1 回目のツールの結果です。そこに `error` があることを確かめます
- 往復の回数（`steps`）も確かめます。上限（既定 4 回）より少ない回数で答えに着いたことが分かります

別の書き方でもよい点: 上限ちょうどで止まる場合（`max_steps=2` で `ToolLoopError`）のテストを足すのも良い確かめ方です。

## 3 本物のモデルで試す（任意）

```python
from roadmap_examples.ollama_client import OllamaChat
from roadmap_examples.p07_tools import run_with_tools

chat = OllamaChat("<ツールに対応したモデル名>", options={"temperature": 0})
run = run_with_tools(chat, [{"role": "user", "content": "会員 M-001 のプランの更新日は？"}], TOOLS)
for message in run.messages:
    print(message["role"], message.get("tool_calls") or message["content"])
```

`run.messages` に、モデルがどのツールをどの引数で呼んだか（assistant の `tool_calls`）と、その結果（tool）が順に残ります。
モデルによっては、ツールを呼ばずに推測で答えることもあります。その場合は、ツールの説明の書き方や、モデルの選び方を見直します。
