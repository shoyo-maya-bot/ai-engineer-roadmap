# 07-2 解答

[07-2 構造化出力とスキーマ検証](../07-2-structured-output.md) の演習の解答の一例です。

## 1 スキーマに urgency を足す

元のスキーマを書き換えず、写してから足します。入れ子の辞書も写すために `copy.deepcopy` を使います。

```python
import copy

from roadmap_examples.p07_structured import CLASSIFY_SCHEMA

SCHEMA_WITH_URGENCY = copy.deepcopy(CLASSIFY_SCHEMA)
SCHEMA_WITH_URGENCY["properties"]["urgency"] = {"type": "string", "enum": ["high", "normal"]}
SCHEMA_WITH_URGENCY["required"].append("urgency")
```

`dict(CLASSIFY_SCHEMA)` のような浅い写しだと、`properties` と `required` は元と同じものを指したままです。
足したキーが元の `CLASSIFY_SCHEMA` にも入り、ほかのテストが失敗します。

## 2 テスト

```python
import json

from roadmap_examples.llm import FakeLLM, Message
from roadmap_examples.p07_structured import ask_json, validate

GOOD = {"category": "bug", "reason": "x", "urgency": "high"}


def test_good_value_passes() -> None:
    assert validate(GOOD, SCHEMA_WITH_URGENCY) == []


def test_missing_urgency_is_reported() -> None:
    problems = validate({"category": "bug", "reason": "x"}, SCHEMA_WITH_URGENCY)
    assert problems == ["$: 「urgency」がありません"]


def test_ask_json_retries_until_urgency_is_present() -> None:
    fake = FakeLLM.of([json.dumps({"category": "bug", "reason": "x"}), json.dumps(GOOD)])
    result = ask_json(fake, [Message("user", "分類して")], SCHEMA_WITH_URGENCY)
    assert result.value == GOOD
    assert result.attempts == 2
    assert "urgency" in fake.calls[1][-1].content  # 頼み直しのメッセージに、足りないキーが書かれている
```

なぜこうするか:

- 2 つ目のテストは、メッセージの全文まで比べています。誤りの伝え方が変わったときに気づけます（伝え方は頼み直しの成功率に効く）
- 3 つ目のテストは、頼み直しのメッセージに何が書かれたかまで確かめます。`FakeLLM.calls` に、受け取ったメッセージが残っています

別の書き方でもよい点: スキーマを関数で作る、テストを `pytest.mark.parametrize` でまとめる、なども構いません。

## 3 format あり・なしで崩れた回数を数える（任意）

```python
import json

from roadmap_examples.evalset import load_cases
from roadmap_examples.ollama_client import OllamaChat
from roadmap_examples.p07_classify import DEFAULT_EVAL
from roadmap_examples.p07_prompt import DEFAULT_SPEC, build_messages
from roadmap_examples.p07_structured import CLASSIFY_SCHEMA, parse_json, validate

cases = load_cases(DEFAULT_EVAL)
for name, fmt in (("format あり", CLASSIFY_SCHEMA), ("format なし", None)):
    llm = OllamaChat("<モデル名>", format=fmt, options={"temperature": 0})
    broken = 0
    for case in cases:
        text = llm.complete(build_messages(DEFAULT_SPEC, case.input)).text
        try:
            broken += bool(validate(parse_json(text), CLASSIFY_SCHEMA))
        except json.JSONDecodeError:
            broken += 1
    print(name, "崩れた回数:", broken, "/", len(cases))
```

ここでは頼み直しをせず、1 回目の出力だけを数えます（`ask_json` を使うと、崩れても直ってしまうため）。
結果は、モデル名・件数・`temperature` と一緒に記録してください。モデルが変わると数字も変わります。
