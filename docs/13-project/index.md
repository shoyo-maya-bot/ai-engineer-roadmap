## 課題

次のどれか 1 つを選び、要件から配備までを 1 人で通します。どれも架空の業務を題材にします。
課題の詳しい説明は準備中です。

| 課題 | 内容 | 状態 |
|---|---|---|
| チャットボット | 社内の手続きの質問に答える | 準備中 |
| 設計書 Q&A（RAG） | 架空の設計書に出典つきで答える | 準備中 |
| レビュー支援エージェント | 変更の差分を読み、確認観点を挙げる（人が承認する） | 準備中 |

## 提出物

- 設計書（要件・構成・RAG か学習かの判断・人の承認を置く場所）
- 評価セットと結果
- 費用の見積もり（ローカルのモデルで動かす場合と、クラウドの API を使う場合）
- 配備の手順
- 振り返り（うまくいったこと・次に直すこと）
