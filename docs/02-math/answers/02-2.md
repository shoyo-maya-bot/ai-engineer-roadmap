# 02-2 解答

[02-2 微分と勾配](../02-2-derivative-gradient.md) の演習の解答の一例です。

## 1 勾配の式と、勾配の確認

内側を u = 2w₀ + w₁ − 5 とおくと、f = u² です。外側の傾きは 2u、内側の傾きは w₀ について 2、w₁ について 1 です。
連鎖律で掛けると、勾配は (2u × 2, 2u × 1) = (4u, 2u) です。

```python
import numpy as np
import pytest

from roadmap_examples.p02_gradient import check_gradient


def f(w: np.ndarray) -> float:
    return float((2 * w[0] + w[1] - 5) ** 2)


def grad_f(w: np.ndarray) -> np.ndarray:
    inner = 2 * w[0] + w[1] - 5  # 内側の値 u
    return 2 * inner * np.array([2.0, 1.0])  # 外側の傾き 2u × 内側の傾き (2, 1)


@pytest.mark.parametrize("w", [[1.0, 1.0], [0.0, 0.0], [3.0, -2.0]])
def test_gradient_formula(w) -> None:
    assert check_gradient(f, grad_f, w) < 1e-6
```

点を 3 つにするのは、1 点だけだと、たまたま合う誤り（その点で 0 になる項の誤りなど）を見逃すからです。

## 2 勾配の逆向きに 20 回進む

```python
def descend(steps: int = 20, lr: float = 0.05) -> tuple[np.ndarray, list[float]]:
    w = np.zeros(2)
    values = [f(w)]
    for _ in range(steps):
        w = w - lr * grad_f(w)
        values.append(f(w))
    return w, values


def test_descent_reduces_value() -> None:
    w, values = descend()
    assert all(a > b for a, b in zip(values, values[1:]))  # 毎回減る
    assert 2 * w[0] + w[1] == pytest.approx(5, abs=1e-3)
```

f の値は 25 → 6.25 → 1.5625 → 0.39 → 0.098 … と、毎回 4 分の 1 になり、20 回でほぼ 0 になりました。
最後の w はおよそ (2.0, 1.0) です。

## 3 2w₀ + w₁ が 5 に近づく理由

f は (2w₀ + w₁ − 5)² なので、2w₀ + w₁ = 5 のとき最小の 0 になります。
勾配の逆向きに進むと f が減るので、2w₀ + w₁ は 5 に近づきます。

なお、2w₀ + w₁ = 5 を満たす w は無数にあります（(2, 1) も (0, 5) も最小）。
勾配はいつも (2, 1) の向きなので、(0, 0) から始めると、その向きにだけ進み、(2, 1) に着きました。
始める点が違えば、別の答えに着きます。答えが 1 つに決まらない問題では、始め方が結果に影響する、という例です。
