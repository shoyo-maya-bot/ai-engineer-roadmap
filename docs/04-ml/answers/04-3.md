## 1 層を 1 つ足す

```python
from roadmap_examples.p04_cluster import MEMBERS, silhouette_by_k

MIDDLE = [(500, 4), (450, 5), (550, 4), (520, 6), (480, 5), (530, 4)]  # そこそこ使い、問い合わせが多い


def test_silhouette_picks_four() -> None:
    scores = silhouette_by_k(range(2, 8), members=MEMBERS + MIDDLE)
    assert max(scores, key=scores.get) == 4
```

手元では k = 4 が 0.726、k = 5 が 0.719 でした。

なぜこうするか:

- 足す層は、ほかの層と離れた位置（利用時間 450〜550 分、問い合わせ 4〜6 件）にします。近すぎると、ほかの層に吸収されます
- k = 4 と k = 5 の差は小さく、データが少し変わると入れ替わりそうです。こういうときは、k = 4 と 5 のまとまりの中身を並べて読み、
  業務で使い分けられるほうを選びます

## 2 文末の形を取り除く

```python
import re

from roadmap_examples.evalset import load_cases
from roadmap_examples.p04_classify import DEFAULT_TRAIN, texts_and_labels
from roadmap_examples.p04_cluster import agreement, cluster_texts

ENDING = re.compile(r"(したいです|たいです|ください|ますか|ません|ています|です|ます|か)?[。？]*$")


def strip_ending(text: str) -> str:
    return ENDING.sub("", text)


def test_strip_ending() -> None:
    assert strip_ending("請求書の送付先の住所を変えたいです。") == "請求書の送付先の住所を変え"


def test_topics_appear_but_categories_still_differ() -> None:
    texts, truth = texts_and_labels(load_cases(DEFAULT_TRAIN))
    labels, terms = cluster_texts([strip_ending(t) for t in texts], 5)
    assert any("請求" in t for t in terms)
    assert agreement(labels, truth) < 0.3
```

手元の結果（上位の文字の組）:

| まとまり | 上位の文字の組 |
|---|---|
| 0 | した・する・され・えて・でき |
| 1 | 画面・の画・払い・面が・終わ |
| 2 | 請求・しい・求書・ほし・てほ |
| 3 | カウ・ント・アカ・メー・ール |
| 4 | の資・資料・もら・らえ・をも |

考察の例:

- 文末の形を取り除くと、「画面」「請求」「アカウント・メール」「資料」のように、話題でまとまるようになりました
- それでも、窓口の分類との一致の度合いは 0.08 で、0.11 から上がりませんでした
- 窓口の分類は、話題だけでなく判断の基準（「請求書の画面が固まる」は bug）で決まっています。話題のまとまりと、窓口の分類は別物です

## 3 新しい窓口の候補を探す手順

例:

1. 分類モデル（04-1）が other と答えた問い合わせ、または other の確率がいちばん高い問い合わせを集める
2. 文末の形を取り除き、文字の組の TF-IDF（または 08 のエンベディング）で、k を 3〜8 の範囲で変えてまとめる
3. シルエット係数と、まとまりごとの上位の文字の組・代表の 5 件を並べて、人が読む
4. 件数が多く、話題がはっきりしたまとまりに名前を付け、新しい窓口の候補として担当者と相談する
5. 窓口を作ると決めたら、その分類の正解つきの例を集め、評価セット（07-5）と学習データに足して、分類モデルを作り直す

なぜこうするか:

- クラスタリングは候補を出すまでです。窓口を作るかどうかは、件数と業務の都合で人が決めます
- 新しい分類を足したら、評価セットにもその分類の件を入れないと、新しい分類の精度を測れません
