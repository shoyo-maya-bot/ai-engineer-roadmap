# 01-1 解答

[01-1 他の言語との違いで覚える Python](../01-1-python-basics.md) の演習の解答の一例です。

## 関数とテスト

```python
from roadmap_examples.p01_pythonic import Inquiry, average_minutes, group_by


def average_minutes_by_category(inquiries: list[Inquiry]) -> dict[str, float | None]:
    groups = group_by(inquiries, lambda q: q.category)
    return {category: average_minutes(items) for category, items in groups.items()}


def test_average_by_category() -> None:
    items = [
        Inquiry("q1", "請求書", "billing", 10),
        Inquiry("q2", "領収書", "billing", 30),
        Inquiry("q3", "ログイン", "account", None),
    ]
    assert average_minutes_by_category(items) == {"billing": 20.0, "account": None}


def test_empty_input() -> None:
    assert average_minutes_by_category([]) == {}
```

なぜこうするか:

- まとめる（`group_by`）と、平均する（`average_minutes`）を分けたままにしています。どちらもテスト済みの部品なので、組み合わせの部分だけを確かめれば済みます
- `{... for ... in ...}` は辞書の内包表記です。Java の `Collectors.toMap` に当たります
- 分が 1 件も分からない分類を `0.0` にしないのは、「0 分で対応できた」と区別できなくなるからです。`None` にして、呼ぶ側に判断させます

## Java で書いた場合との比較

Java（Stream）でも短く書けますが、`null` の扱い（平均が出せない分類）を別に考える必要があります。
Python では `average_minutes` が `None` を返すので、内包表記の 1 行で済みます。

## 別の書き方

`statistics.mean` を使っても構いません。ただし、空の list を渡すと `StatisticsError` になるので、先に件数を確かめます。

```python
import statistics


def average_or_none(values: list[int]) -> float | None:
    return statistics.mean(values) if values else None
```

テストが通り、`None` になる場合を説明できれば、どの書き方でも正解です。
