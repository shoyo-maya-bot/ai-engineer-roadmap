# 学び方

この教材を始める前に読むページです。演習の環境の作り方と、費用をかけずに進める方法をまとめます。

## 演習の環境

演習のコードは、リポジトリの `examples/` にあります。Python {{ versions.python }} と、パッケージ管理の uv（{{ versions.uv }}）を使います。
テストは pytest、静的解析と書式は ruff です。版は `examples/pyproject.toml` と `examples/uv.lock` で固定しています。

```bash
git clone https://github.com/shoyo-maya-bot/ai-engineer-roadmap.git
cd ai-engineer-roadmap/examples
uv sync --locked          # 仮想環境（.venv）を作り、固定した版で入れる
uv run pytest             # 演習のテスト（LLM は呼ばない）
uv run ruff check .       # 静的解析
```

- Windows・macOS・Linux のどれでも動きます。Windows では PowerShell で同じコマンドを使えます
- uv が Python 本体も用意します（手元に別の版の Python があっても構いません）
- Linux の基本操作は 01 で扱います。Windows の人は WSL を使うと、教材の手順とそろいます

## LLM はローカルのモデルが基本

LLM を使う演習（06 以降）は、手元で動かすローカルのモデル（Ollama など）を基本にします。
お金はかかりませんが、モデルの大きさに応じたメモリが要ります。どの大きさのモデルを選ぶかは 06 で扱います。

- 演習のコードは、LLM を呼ぶ部分を `LLMClient`（インターフェース）にしています。本物のモデルと、決まった応答を返す偽の実装（`FakeLLM`）を差し替えられます
- テストと CI は偽の実装だけを使い、LLM を呼びません。テストの結果が毎回同じになり、費用もかかりません

## 従量課金の API は「任意」

クラウドの LLM の API（使った量に応じてお金がかかるもの）を使う演習は、すべて **任意** です。
ローカルのモデルだけで、どの部の成果物も作れます。試す場合は、始める前に次を決めてください（詳しくは 07 の費用の章）。

1. **上限の金額** を決め、API の管理画面で利用の上限と通知を設定する
2. **キーの置き場所** は `.env` だけにする（リポジトリにコミットしない。`.env.example` を写して使う）
3. **止め方** を先に確かめる（キーの無効化・削除の手順。使い終わったらキーを消す）
4. コードの側でも、呼び出しの回数とトークン数に上限を設ける（10 のエージェントでは特に）

## 章の読み方

- どの章も「何か → なぜ必要か → どうやるか → 演習 → もし〇〇がなかったら？ → 理解度チェック」の順です
- 演習は、先に自分で解いてから解答のページを見てください。解答は「一例」です。テストが通り、理由を説明できれば別の書き方でも構いません
- 本文のコードのうち、実行できるものは `examples/` に実物があります（本文はそこからの引用で、CI が一致を確かめています）
