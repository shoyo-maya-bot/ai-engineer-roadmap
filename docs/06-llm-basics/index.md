# 06 LLM の基礎

!!! abstract "到達目標"
    - トークン数・コンテキストの長さ・モデルの大きさから、費用と制約を見積もれる

## 前提

- 前提の部: [01 Python と基礎](../01-python/index.md)
- 05 を終えていると仕組みの理解が深まりますが、近道では 05 を飛ばして進められます。
- LLM はローカルのモデル（Ollama）で動かします。演習のコードは `examples/` にあり、テストは LLM を呼びません。
- クラウドの API と比べる演習は任意です。ローカルのモデルだけで成果物を作れます。
