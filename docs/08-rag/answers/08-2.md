## 1・2 大きさを変えて比べる

```python
import pytest

from roadmap_examples.p08_chunk import chunk_markdown
from roadmap_examples.p08_rag import DEFAULT_DOCS

API_DOC = (DEFAULT_DOCS / "02-api.md").read_text(encoding="utf-8")


def body(chunk_text: str, heading: str) -> str:
    """チャンクの本文（先頭に付けた見出しの行を除く）."""
    return chunk_text.removeprefix(f"{heading}\n") if heading else chunk_text


def test_small_chunks_fit_max_chars() -> None:
    chunks = chunk_markdown(API_DOC, "02-api.md", max_chars=100, overlap=20)
    assert all(len(body(c.text, c.heading)) <= 100 for c in chunks)


@pytest.mark.parametrize("max_chars", [100, 400, 1000])
def test_rate_limit_sentence_is_not_split(max_chars: int) -> None:
    chunks = chunk_markdown(API_DOC, "02-api.md", max_chars=max_chars, overlap=20)
    assert any("1 分間に 60 回まで" in c.text for c in chunks)


def test_count_chunks() -> None:
    counts = {m: len(chunk_markdown(API_DOC, "02-api.md", max_chars=m, overlap=20)) for m in (100, 400, 1000)}
    assert counts[100] >= counts[400] >= counts[1000]
    print(counts)  # uv run pytest -s で表示される
```

なぜこうするか:

- 本文の長さは、先頭に付けた見出しの行を除いて数えます。見出しは `max_chars` の外で足しているからです
- 「切れずに入っている」は、文がそのまま含まれるチャンクが 1 つ以上あることで確かめます
- 数そのもの（何件か）は、設計書を直すと変わります。テストでは「小さいほど多い（同じ以上）」という関係だけを確かめます

題材の `02-api.md` では、100 で 12 件、400 と 1000 ではどちらも 4 件でした（`overlap=20`）。節がもともと短く、節をまたいでまとめることはしないためです。
`max_chars` を大きくしても、見出しで区切った節より大きなチャンクにはなりません。

## 3 本物のエンベディングで比べる（任意）

```python
import numpy as np

from roadmap_examples.ollama_client import OllamaEmbedder
from roadmap_examples.p08_chunk import chunk_markdown
from roadmap_examples.p08_rag import DEFAULT_DOCS
from roadmap_examples.p08_search import normalize

embedder = OllamaEmbedder("<エンベディングのモデル名>")
question = "API は 1 分間に何回まで呼べますか？"
api_doc = (DEFAULT_DOCS / "02-api.md").read_text(encoding="utf-8")
q = normalize(np.asarray(embedder.embed([question])))[0]
for max_chars in (100, 400, 1000):
    chunks = chunk_markdown(api_doc, "02-api.md", max_chars=max_chars, overlap=20)
    m = normalize(np.asarray(embedder.embed([c.text for c in chunks])))
    scores = m @ q
    top = np.argsort(-scores)[:3]
    print(max_chars, [(chunks[i].heading.split(" > ")[-1], round(float(scores[i]), 3)) for i in top])
```

表にするときは、使ったモデル名と `overlap` も書きます。見るところ:

- 1 位が「呼び出しの回数の制限」の節になっているか
- `max_chars` が小さいと、1 位と 2 位の点の差が開くか、縮むか（小さいチャンクは話題が絞られる）
- 類似度の値そのものは、モデルごとに尺度が違います。モデルをまたいで値を比べず、順位で比べます
