## 1・2 Excel を作って Markdown にする

```python
from pathlib import Path

from openpyxl import Workbook

from roadmap_examples.p08_ingest import xlsx_to_markdown


def make_error_codes(path: Path) -> None:
    wb = Workbook()
    ws = wb.active
    ws.title = "エラーコード"
    ws.append(["コード", "HTTP", "意味"])
    ws.append(["E-101", 400, "入力の形が正しくない"])
    ws.append(["E-201", 401, "トークンが無い\nまたは期限切れ"])
    ws.append(["E-401", 429, "呼び出しの回数の制限を超えた"])
    wb.save(path)


def test_error_codes_to_markdown(tmp_path: Path) -> None:
    path = tmp_path / "error-codes.xlsx"
    make_error_codes(path)
    markdown = xlsx_to_markdown(path)
    table = [line for line in markdown.splitlines() if line.startswith("|")]
    assert len(table) == 5  # 見出し・区切り・3 行
    assert "| E-201 | 401 | トークンが無い または期限切れ |" in markdown
```

なぜこうするか:

- 表の行は `|` で始まる行として数えます。見出しの行と区切りの行（`|---|`）を含めて 5 行です
- 改行は空白になります。Markdown の表の 1 行は、改行を含められないからです
- 数（`400`）は、整数のまま表に入ります（`cell_text` が `400.0` のような表記にしない）

別の書き方でもよい点: 表をすべて文字列として比べる（`assert table == [...]`）書き方でもかまいません。

## 3 数式のセル

```python
def test_formula_without_cached_value(tmp_path: Path) -> None:
    wb = Workbook()
    wb.active.append(["項目", "値"])
    sheet = wb.create_sheet("計算")
    sheet.append(["合計", "=1+1"])
    path = tmp_path / "formula.xlsx"
    wb.save(path)
    markdown = xlsx_to_markdown(path)
    assert "| 合計 |" in markdown
    assert "2" not in markdown.split("## 計算")[1]
```

結果: 「計算」のシートは `| 合計 |` だけの表になり、`=1+1` の値（2）は入りません。

理由: `data_only=True` は、数式のセルについて「最後に Excel で保存したときの値」を読みます。
openpyxl で書いたファイルは、Excel で一度も計算・保存されていないので、その値がありません。
値の無いセルは空になり、右端の空の列は表から落ちます。

業務での扱い方の例:

- 取り込む前に、Excel で開いて保存し直す（値が書き込まれる）
- 取り込んだ表に、空の列や空のセルが多いシートを一覧にして、人が確かめる
- `data_only=False` で読むと数式（`=1+1`）そのものが取れます。数式の中身が答えの手がかりになる文書なら、両方を書く手もあります
