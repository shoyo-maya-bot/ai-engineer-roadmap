# 08 RAG とベクトルデータベース

!!! abstract "到達目標"

## 前提

- 前提の部: [07 プロンプトと API](../07-prompt-api/index.md)（評価セットの形式と、LLM の出力の確かめ方）
- LLM とエンベディングは、ローカルのモデル（Ollama）で動かします。演習のコードは `examples/` にあり、テストは LLM もエンベディングも呼びません。
- ベクトル検索は NumPy で自分で書きます。ベクトル用のデータベースの製品は、08-3 で選び方だけを紹介します。
