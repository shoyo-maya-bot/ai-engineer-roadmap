# 備品貸出システム 設計書: API

## 認証

API を呼ぶには、アクセストークンが要る。トークンは、ログインの API で、社員番号とパスワードを送ると発行される。

- アクセストークンの有効期限は 30 分
- 有効期限が切れたら、リフレッシュトークンで新しいアクセストークンをもらう。リフレッシュトークンの有効期限は 7 日
- トークンは、リクエストの Authorization ヘッダーに Bearer の形で付ける

## エンドポイント

| メソッド | パス | 内容 |
|---|---|---|
| GET | /items | 備品の一覧。種類と空き状況で絞り込める |
| GET | /items/{item_id} | 備品 1 件の詳細 |
| POST | /loans | 貸し出しを申し込む |
| POST | /loans/{loan_id}/return | 返却する |
| POST | /loans/{loan_id}/extend | 返却期限を延長する |

## 呼び出しの回数の制限

同じ利用者からの呼び出しは、1 分間に 60 回までとする。
超えた場合は 429 を返し、Retry-After ヘッダーに、次に呼べるまでの秒数を入れる。
ほかの社内システムからの呼び出しは、システムごとに 1 分間に 600 回までとする。

## エラーコード

| HTTP | コード | 意味 |
|---|---|---|
| 400 | E-101 | 入力の形が正しくない |
| 401 | E-201 | トークンが無い、または有効期限が切れている |
| 403 | E-202 | その操作の権限が無い |
| 404 | E-301 | 指定した備品や貸し出しが無い |
| 409 | E-302 | 備品がすでに貸し出し中、または予約済み |
| 429 | E-401 | 呼び出しの回数の制限を超えた |
| 503 | E-501 | 稼働時間外、またはメンテナンス中 |
