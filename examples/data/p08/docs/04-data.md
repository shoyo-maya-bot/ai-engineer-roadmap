# 備品貸出システム 設計書: データ

## 貸し出しの決まり

- 1 人が同時に借りられるのは 5 点まで
- 貸出期間は、借りた日から 14 日
- 返却期限の延長は 1 回だけ、7 日間できる。ほかの人が予約している備品は延長できない
- 延滞中の利用者は、新しく借りられない

## テーブル

### items（備品）

| 列 | 型 | 内容 |
|---|---|---|
| item_id | 文字列 | 備品の番号（例: PC-0012） |
| category | 文字列 | 種類（pc・projector・camera など） |
| name | 文字列 | 備品の名前 |
| status | 文字列 | available（空き）・loaned（貸し出し中）・repair（修理中） |

### loans（貸し出し）

| 列 | 型 | 内容 |
|---|---|---|
| loan_id | 整数 | 貸し出しの番号 |
| item_id | 文字列 | 備品の番号 |
| user_id | 文字列 | 利用者の社員番号 |
| loaned_on | 日付 | 借りた日 |
| due_on | 日付 | 返却期限 |
| returned_on | 日付 | 返した日（返していなければ空） |
| extended | 真偽 | 延長したか |

### users（利用者）

| 列 | 型 | 内容 |
|---|---|---|
| user_id | 文字列 | 社員番号 |
| role | 文字列 | member（一般の社員）・staff（備品の担当者）・admin（システムの管理者） |
