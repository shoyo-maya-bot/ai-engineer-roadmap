# 備品貸出システム 設計書: 概要

この設計書は、教材の演習のために作った架空のシステムのものです。

## 目的

社内の備品（ノート PC・プロジェクター・カメラなど）の貸し出しと返却を、紙の台帳から Web の画面に移す。
だれが、どの備品を、いつまで借りているかを、いつでも確かめられるようにする。

## 利用者

| 利用者 | できること |
|---|---|
| 一般の社員 | 備品を探す・予約する・借りる・返す・延長する |
| 備品の担当者 | 備品を登録する・貸し出しを承認する・延滞を確かめる |
| システムの管理者 | 利用者と権限を管理する・バッチの結果を確かめる |

## 構成

システムは、Web の画面・API・夜間バッチ・データベースの 4 つでできている。

- Web の画面は API だけを呼ぶ。データベースには直接つながない
- API は、画面からの操作と、ほかの社内システムからの問い合わせを受ける
- 夜間バッチは、返却期限の通知と延滞の集計をする（詳しくは「夜間バッチ」の設計書）
- データベースは 1 つで、テーブルの定義は「データ」の設計書に書く

## 稼働時間

画面と API は、毎日 6:00 から 23:00 まで使える。23:00 から翌 6:00 までは、夜間バッチとバックアップのために止める。
止めている間に API を呼ぶと、503 を返す。
