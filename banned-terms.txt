# check_chapters.py の禁止語（docs/ と examples/ のファイルで、大文字小文字を区別せずに探す）.
# 教材のサンプルは架空のもの（会員・問い合わせ・設計書など）だけを使う方針（AGENTS.md「サンプル・固有名詞」）.
# 法人の名前や個人のメールアドレス・ローカルのユーザーパス・チャットの ID・API キーが紛れ込んだら CI で止める.
# 1 行 1 語. 行頭の # はコメント（語の後ろの「 #」から行末もコメント）. 空にしない（空だと check_chapters.py が失敗する）.
#
# 書き方:
#   ふつうの語        大文字小文字を区別せず、どこにあっても当てる（全角・半角は NFKC でそろえてから比べる）
#   path:<パス>       大文字小文字を区別し、行頭・空白・クォート・括弧の直後から始まるパスの形のときだけ当てる
#   re:<正規表現>     正規表現（大文字小文字を区別する）. ID やキーのように形で見分けるもの

# チャットツールのユーザー ID・チャンネル ID の形（U0 / W0 / C0 で始まる英大文字と数字）
re:\b[UWC]0[A-Z0-9]{7,11}\b
